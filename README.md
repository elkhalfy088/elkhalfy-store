# Elkhalfy Store

نسخة مصدر لمتجر إلكتروني عربي RTL، مبنية لتكون نقطة بداية قابلة للتوسعة وليست مجرد صفحة HTML. المتجر يبدأ فارغًا من المنتجات والسلايدر حتى تضيف المحتوى من لوحة التحكم.

## الموجود في المشروع

- متجر عام متجاوب مع RTL ووضع ليلي.
- لوحة تحكم محمية بتسجيل دخول جلساتي.
- إضافة وتعديل وحذف المنتجات والتصنيفات.
- صور متعددة للمنتج، صورة مصغرة، وفيديو MP4 اختياري.
- إدارة شرائح السلايدر مع إمكانية تفعيل/تعطيل كل شريحة.
- إدارة الطلبات وتغيير حالتها.
- نموذج تواصل ورسائل داخل لوحة التحكم.
- إعدادات المتجر: الاسم، الشعار النصي، العملة، الوصف، روابط التواصل.
- SQLite محلي قابل للنقل، ومجلد uploads للملفات المرفوعة.
- حماية أساسية للخادم: Helmet، تحديد معدل الطلبات، جلسات HttpOnly، CSRF token للعمليات الإدارية، تحقق من المدخلات، منع رفع أنواع غير مسموحة، وأسماء ملفات عشوائية.

## التشغيل

```bash
cp .env.example .env
# عدّل ADMIN_EMAIL و ADMIN_PASSWORD و SESSION_SECRET
npm install
npm start
```

افتح:

- المتجر: http://localhost:3000
- لوحة التحكم: http://localhost:3000/2009elkhalfyabdeladimadmin1nembre

بيانات الدخول الأولى تأتي من `.env`. عند تشغيل الخادم أول مرة يتم إنشاء المستخدم الإداري تلقائيًا. غيّر كلمة المرور قبل أي استخدام حقيقي.

## ملاحظات أمنية مهمة

لا يوجد نظام يمكن وصفه بأنه آمن 100%. هذه الحزمة تتجنب الخطأ الموجود في الملف السابق: لا توجد مفاتيح Firebase أو بيانات حساسة داخل المتصفح، ولا تُرسل رموز التعبئة إلى كود الواجهة العام. قبل النشر الفعلي:

1. استخدم HTTPS خلف reverse proxy.
2. ضع `SESSION_SECRET` عشوائيًا قويًا ولا ترفعه إلى Git.
3. استخدم قاعدة بيانات مُدارة ونسخًا احتياطية.
4. اربط بوابة دفع موثوقة بدل استقبال بيانات حساسة في نموذج مخصص.
5. راجع الصلاحيات، سجلات التدقيق، سياسة الخصوصية، وقوانين بلدك.

هذه نسخة المصدر فقط كما طلبت؛ لا يوجد نشر أو دومين أو ربط دفع داخل الملف المضغوط. مسار لوحة التحكم مخصص كما طلبت، لكنه ليس بديلاً عن كلمة المرور والمصادقة.
